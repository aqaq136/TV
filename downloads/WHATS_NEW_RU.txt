MetoxTV 4.0.2 — погода и подключение Яндекса

Откройте виджет погоды на главном экране.
Либо: Инструменты → Погода: Яндекс, источник и обновление.

ЯНДЕКС ПОГОДА
Кнопка «Подключить ключ Яндекс.Погоды» принимает ваш личный ключ
API погодных данных с доступом к REST API.
Кабинет: https://yandex.ru/pogoda/b2b/console
Тариф и лимиты задаются у Яндекса. Общего ключа в приложении нет.
Ключ хранится в приватных данных ТВ и не попадает в резервную копию.
Для старого тарифа информера есть отдельный пункт выбора источника.

БЕЗ КЛЮЧА
Виджет использует Open-Meteo с явной подписью источника.
«Открыть Яндекс Погоду» показывает страницу города в браузере,
для этой ссылки API-ключ не нужен.

ВЫБОР ГОРОДА
Встроенный список городов, онлайн-поиск или ввод координат.
Если поиск недоступен, список и координаты остаются доступными.
Геолокация не запрашивается.

ОБНОВЛЕНИЕ
Каждые 30 минут, пока открыт главный экран или экран погоды.
Кнопка «Обновить сейчас» запускает ручную загрузку.
При ошибке остаётся последняя сводка, повтор через 5 минут.
Видны источник, время получения и признак устаревания через 2 часа.
Подробная причина ошибки — на экране погоды.
При переходе в другие приложения запрос останавливается.
После смены города ответ для старого города отбрасывается.

УСТАНОВКА
Версия 4.0.2, код 19, пакет com.gathin.tvhome.
Установите поверх предыдущей нашей версии, не удаляя приложение.
Подпись сохранена. Русский интерфейс и эффекты 4.0 сохранены.

ПРОВЕРКА
392 JVM-теста; Android Lint без ошибок.
Шесть сценариев на эмуляторе Android TV 9.
Ответы HTTPS API проверены детерминированными фикстурами.
Живой запрос к Яндексу без вашего рабочего ключа не подтверждён.
На физическом Sber TV 4.0.2 отдельно не проверялась.
