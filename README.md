# ErokhinTV Premium 3.4

Лаунчер для Android TV, интерфейс по референсу ErokhinTV Premium. Требуется Android 8.0 или новее. Совместимость с конкретной моделью Сбер ТВ нужно проверить на устройстве.

## Скачать и установить

- [Архив с APK и полной инструкцией](https://github.com/aqaq136/TV/raw/refs/heads/erokhintv-premium/downloads/ErokhinTV_Install_Complete.zip)
- [APK лаунчера](https://github.com/aqaq136/TV/raw/refs/heads/erokhintv-premium/downloads/ErokhinTV_Premium_Interface.apk)
- [Необязательный модуль эфирного ТВ](https://github.com/aqaq136/TV/raw/refs/heads/erokhintv-premium/downloads/ErokhinTV_EfirTV.apk)
- [Полная инструкция по установке](downloads/INSTALL_RU.txt)

Скачайте и распакуйте архив на компьютере. Внутри откройте файл `ИНСТРУКЦИЯ.txt`: описаны установка с флешки, через ADB, выбор домашнего экрана и устранение ошибок. Не удаляйте штатный лаунчер Сбер ТВ.

APK подписаны отладочным ключом. Модуль эфирного ТВ только открывает системное ТВ-приложение и не содержит каналов или IPTV-плейлистов.

## Разработка

[Описание изменений и команды сборки](README-EROKHINTV.md). Требуются полный JDK 17 и Android SDK 34. Сборка обоих модулей и 321 JVM-тестов прошли успешно. На реальном Сбер ТВ и эмуляторе проверка не выполнялась.

## Версия 3.3

Настраиваемое избранное (до 24 приложений), перемещение ярлыков удержанием OK, три темы, свои обои, имя в приветствии, отступы от краёв и крупные подписи. Откройте **Настройки лаунчера → Оформление и избранное**. Wi-Fi, Bluetooth и загрузки GitHub доступны оттуда же, если прошивка предоставляет обработчики.

[Инструкция по обновлению и ошибке подписи](downloads/INSTALL_RU.txt). Пакет сохранён: `com.gathin.tvhome`; параллельная копия не создаётся. Поверх нашего предыдущего APK из этой ветки обновление сохраняет настройки. Для более старой установки с другой подписью может потребоваться удаление с потерей её настроек.

[Скрипт установки Windows](downloads/INSTALL_WINDOWS.cmd) работает при уже настроенном ADB-подключении, не удаляет приложения и не меняет системный лаунчер автоматически. На телевизоре изменения ещё не проверены.

## Исправление 3.3.1

Серый фон теперь принадлежит всему блоку приложений, а не только первой док-строке. Дополнительные ряды и плитки при прокрутке располагаются на общей панели. Настройка прозрачности панели сохранена. Обновление подписано тем же ключом и устанавливается поверх версии 3.3.

## Версия 3.4 — инструменты

Кнопка **«Инструменты»** в нижнем ряду главного экрана (или в настройках лаунчера) открывает:

- Форму плиток: широкие, квадратные или компактные.
- Установку обычного APK с USB через системный выбор файла и системный установщик Android. Для ErokhinTV потребуется разрешить установку неизвестных приложений. XAPK/APKM и split-наборы не поддерживаются.
- Выбор города и получение погоды Open-Meteo без ключа API и геолокации. Сохранённая сводка с датой отображается на главном экране; обновление запускается вручную.
- Состояние Wi-Fi/Ethernet/VPN и проверку доступности Cloudflare по HTTPS.
- Оценку скорости загрузки: после подтверждения скачивается 10 МБ с Cloudflare. Отдача не проверяется, результат приблизительный.
- Удаление пользовательских приложений с отдельным подтверждением названия/пакета и последующим системным подтверждением. Сам лаунчер и системные приложения защищены в этом разделе.
- Отдельные переключатели звуков перемещения и OK, три уровня громкости; оба выключенных переключателя отключают звуки лаунчера. Звуки Android и других приложений не меняются.
- Диагностику: версия, модель, Android, размер экрана, свободное место и состояние подключения. Отчёт можно просмотреть, сохранить TXT или отправить через системное меню. Он не отправляется автоматически и не содержит IP/MAC, серийного номера, паролей или списка приложений.

Онлайн-проверки требуют доступа телевизора к `geocoding-api.open-meteo.com`, `api.open-meteo.com` и `speed.cloudflare.com`. В облачной среде проверки поиска города и Cloudflare вернули HTTP 403 сетевой политики; живое получение погоды и скорости здесь не подтверждено. Парсинг ответов и геометрия плиток проверяются JVM-тестами. Выбор USB, системная установка/удаление и звуки требуют проверки на самом телевизоре.
