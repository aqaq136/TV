# MetoxTV 3.5.0 для Sber SDX-50U4010B

Лаунчер с управлением пультом для **Sber SDX-50U4010B с SaluteTV, Android 9 и прошивкой TVOS-04.16.031.01.12**. Устанавливается как обычный APK, без перепрошивки. Владелец подтвердил работу сборки 3.4 с прежним названием. В 3.5.0 добавлены поиск приложений, недавние запуски, резервные копии и управление быстродействием. Новая версия ещё не проверена на самом телевизоре. Это **не подтверждает совместимость со всеми Сбер ТВ и Салют ТВ**.

## Новое в 3.5.0

- **Поиск и приложения:** лупа в шапке, кнопка Search на поддерживаемых пультах или пункт в инструментах. Поиск по названию и пакету, без учёта регистра и диакритики; русский транслит: `kino` → «Кинопоиск».
- **Все / Избранное / Недавние:** сортировка результатов по совпадению; недавние — по времени запуска, избранные — в вашем порядке. OK открывает приложение, удержание OK или Menu предлагает действия с ярлыком и избранным.
- **Резервные копии:** ZIP через системный выбор файла. Переносятся оформление, избранное, порядок плиток, ярлыки, звуки, часы и свои обои. Перед заменой — проверка файла, подтверждение и локальная копия прежних настроек. Последнее восстановление можно отменить.
- **Быстродействие:** быстрый режим без анимаций, сбалансированный и все эффекты. Часы при простое можно включить отдельно; таймер работает только на главном экране.
- **История запусков:** теперь учитываются основные плитки, избранное, библиотека и поиск. В инструментах можно остановить запись и очистить сохранённое время запусков.
- **Подсказки по пульту** внутри приложения. Новые экраны переведены на русский и английский и используют выбранный язык лаунчера.

Подробности, ограничения резервных копий и порядок проверки на ТВ: [описание релиза 3.5.0](docs/releases/3.5.0.md).

## Что важно перед установкой

- **Не удаляйте и не отключайте `ru.sberdevices.starlauncher`, системные настройки и системные приложения.** Для обычной установки MetoxTV этого не требуется.
- Не запускайте для установки `build-and-install.sh` и `build-and-install.ps1` из исходников. Это унаследованные сценарии для других конфигураций: в них есть отключение штатного лаунчера, назначение Home и выдача системных разрешений. Они не являются инструкцией для описанного Сбер ТВ.
- Не используйте команды `pm disable-user`, `pm uninstall --user 0` для системных пакетов, не меняйте `enabled_accessibility_services` и не выдавайте `WRITE_SECURE_SETTINGS` по случайной инструкции. Поддерживаемый ниже путь установки этого не делает.
- Перед назначением MetoxTV домашним экраном убедитесь, что умеете открыть штатные настройки и вернуть прежний Home. Сначала запустите приложение обычным способом и проверьте пульт.
- Из-за имени пакета `com.gathin.tvhome` новая сборка может конфликтовать с другой установленной версией TVHome. Не удаляйте её автоматически: сначала прочитайте раздел об обновлении.

## Установка с флешки

1. Скачайте и **распакуйте ZIP на компьютере**. Скопируйте `MetoxTV.apk` на флешку.
2. Подключите флешку к телевизору и откройте APK в доступном файловом менеджере.
3. Если Android запросит разрешение установки неизвестных приложений, разрешите его именно этому файловому менеджеру. Название пункта меню зависит от прошивки.
4. Подтвердите установку и откройте MetoxTV из списка приложений. Включать режим разработчика для этого способа не нужно.
5. Проверьте стрелки, OK, возврат из приложений, настройки и видимость всех рядов плиток.
6. Только после проверки при желании выбирайте MetoxTV в штатных настройках домашнего приложения. Если такого выбора нет или Home возвращает экран Сбер, используйте лаунчер как обычное приложение. Не отключайте штатный Home ради обхода ограничения.

Если в вашей прошивке нет файлового менеджера или установки APK, смотрите ADB ниже. Отсутствие этих функций не означает, что их нужно обходить системными командами.

## Установка через ADB

Нужны [официальные Android SDK Platform-Tools](https://developer.android.com/tools/releases/platform-tools), доступная в прошивке отладка и уже настроенное подключение к телевизору. [Порядок подключения и сопряжения](downloads/INSTALL_RU.txt). Не все телевизоры используют порт 5555.

Проверьте, что подключён **именно нужный телевизор**:

```bat
adb.exe devices
```

При статусе `device` и одном подключённом устройстве:

```bat
adb.exe install -r MetoxTV.apk
adb.exe shell am start -n com.gathin.tvhome/.MainActivity
```

Эти команды устанавливают/обновляют и открывают только MetoxTV. Они не меняют Home и не отключают штатный экран. Если устройств несколько, используйте `adb.exe -s АДРЕС_НУЖНОГО_ТВ ...`.

В PowerShell при запуске из папки Platform-Tools пишите `./adb.exe`, в macOS/Linux — `./adb`. На телевизоре подтвердите запрос доверия к своему компьютеру. После установки можно отключить отладку; для работы лаунчера она не нужна. Не открывайте её порт в Интернет.

[INSTALL_WINDOWS.cmd](downloads/INSTALL_WINDOWS.cmd) — необязательная оболочка этих же операций: предполагает уже настроенный ADB, не удаляет приложения, не выбирает Home и не устанавливает отладку за пользователя.

## Обновление и ошибка подписи

**Поверх предыдущих APK, выложенных нами в этой ветке с тем же ключом:** используйте `adb install -r` или штатную установку обновления. Данные приложения должны сохраниться.

**`INSTALL_FAILED_UPDATE_INCOMPATIBLE`:** уже установлен `com.gathin.tvhome` с другой подписью. Параметр `-r` это не исправит. Без потери данных обновление возможно только APK, подписанным прежним ключом. Если ключ недоступен, можно осознанно удалить старую пользовательскую версию и поставить новую — её локальные настройки будут потеряны.

Перед удалением старой версии верните штатный Home и сохраните нужные настройки. Команду удаления намеренно не включаем в обычный установочный сценарий; отдельная инструкция есть в [INSTALL_RU.txt](downloads/INSTALL_RU.txt). Штатный лаунчер Сбер ТВ удалять нельзя.

Текущие APK подписаны отладочным ключом проекта. Собственная пересборка на другом компьютере обычно получит другой ключ и может не установиться поверх готового APK. Ключи подписи не входят в репозиторий.

## Управление и возможности

| Действие | Управление |
| --- | --- |
| Перемещение и запуск | Стрелки пульта и OK |
| Меню основной плитки | Удержание OK: перемещение, избранное, сведения, подтверждённое удаление |
| Порядок избранного | Удержание OK на избранном ярлыке |
| Выбор избранных приложений | Кнопка `+`; до 24 приложений, ряд прокручивается |
| Оформление | Настройки лаунчера → «Оформление и избранное» |
| Служебные функции | Нижняя кнопка «Инструменты» |

В оформлении: темы, свои обои, имя в приветствии, крупные подписи и отступы от краёв. В основных настройках: число колонок, часы, прозрачность панели и анимации.

В инструментах:

- широкие, квадратные и компактные плитки;
- установка обычного APK с флешки через системный выбор файла и установщик; XAPK/APKM и split-наборы не поддерживаются, предел файла — 512 МБ;
- ручной выбор города и обновление погоды; на главном экране видны сохранённая сводка и время её получения;
- состояние подключения и оценка скорости загрузки: после подтверждения скачивается 10 МБ с Cloudflare, скорость отдачи не измеряется;
- удаление пользовательского приложения с подтверждением названия, пакета и затем подтверждением Android; системные приложения и сам лаунчер из этого раздела не удаляются;
- отдельные переключатели звуков перемещения и OK, три уровня громкости; выключение обоих отключает звуки лаунчера, но не звуки Android и других приложений;
- диагностический отчёт: просмотр, сохранение TXT и системное меню «Поделиться».

«Убрать из избранного» удаляет только ярлык. «Удалить приложение» удаляет приложение и его локальные данные.

## Разрешения, сеть и данные

Для первого запуска не нужны root, перепрошивка, доступность/Accessibility или выдача привилегированных разрешений через ADB. В исходном манифесте есть унаследованные объявления `ACCESS_FINE_LOCATION`, `WRITE_SECURE_SETTINGS` и службы Accessibility; обычная установка не выдаёт привилегированные разрешения и не включает эти службы. Для перечисленных выше функций включать их не нужно.

Установка APK из самого MetoxTV требует отдельного разрешения Android «Установка неизвестных приложений» **для MetoxTV**. Его можно отозвать после установки. Доступ к выбранному файлу даётся через системное окно выбора, а не ко всей флешке. Все ограничения производителя сохраняются.

| Внешний сервис | Что отправляется и когда |
| --- | --- |
| `geocoding-api.open-meteo.com` | Введённое название города при поиске |
| `api.open-meteo.com` | Координаты выбранного города при ручном обновлении погоды |
| `speed.cloudflare.com` | HTTPS-запрос при проверке подключения или подтверждённом тесте скорости; сервер видит сетевой адрес соединения |
| GitHub | Открытие страницы обновлений пользователем |

Погода: [Open-Meteo](https://open-meteo.com/), данные CC BY 4.0. Геолокация для выбора города не запрашивается. Фонового опроса погоды и автоматических тестов скорости нет. Недоступность одного сервиса не доказывает отсутствие интернета.

Настройки, избранное, выбранные обои и последняя погода хранятся в данных приложения. Диагностический отчёт не отправляется автоматически. Он содержит модель, версию Android, параметры экрана, свободное место и состояние подключения; не включает серийный номер, IP/MAC, пароли, список приложений или системные логи. Сохранение и отправка требуют действия пользователя.

## Возврат к штатному экрану

1. Откройте системные настройки телевизора, пока MetoxTV ещё установлен.
2. Если вы меняли домашнее приложение, выберите обратно штатный Home доступным в этой прошивке способом.
3. Проверьте, что кнопка Home открывает штатный экран и настройки доступны.
4. После этого при желании удалите **только MetoxTV** обычным удалением приложения. Это удалит его настройки. Необязательный модуль «Эфирное ТВ» удаляется отдельно.

Если выбор Home заблокирован прошивкой, не отключайте системные пакеты. При недоступном интерфейсе и заранее разрешённом ADB можно открыть общие настройки командой:

```bat
adb.exe shell am start -a android.settings.SETTINGS
```

Команда только открывает настройки; наличие обработчика зависит от прошивки. **Только для указанного Sber SDX-50U4010B** с сохранённым включённым `ru.sberdevices.starlauncher` можно попытаться открыть штатный экран без изменения приложения по умолчанию:

```bat
adb.exe shell am start -a android.intent.action.MAIN -c android.intent.category.HOME -p ru.sberdevices.starlauncher
```

Эта вспомогательная команда отдельно на устройстве не проверялась; успешное открытие экрана не означает, что Home назначен по умолчанию. Если обработчик не найден, используйте настройки, а не угадывайте имя Activity. Никаких команд отключения системных пакетов для этого не требуется. Для другой модели имя штатного лаунчера нельзя брать из этой инструкции.
