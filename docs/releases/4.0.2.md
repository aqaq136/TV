# MetoxTV 4.0.2 — погода и подключение Яндекса

Раньше погода обновлялась только вручную, а поиск города зависел от одного сервиса. В 4.0.2 появился отдельный экран погоды: нажмите виджет на главном экране или откройте его из инструментов.

## Подключение Яндекс.Погоды

1. Создайте личный ключ API погодных данных с доступом к REST API в [кабинете Яндекса](https://yandex.ru/pogoda/b2b/console). Тариф и лимиты определяет Яндекс.
2. В экране погоды выберите город из списка, найдите по названию или введите координаты.
3. Нажмите «Подключить ключ Яндекс.Погоды» и введите ключ на телевизоре. Дождитесь ответа сервиса. При успехе источник изменится на «Яндекс Погода», появятся температура, описание и ветер.
4. Для архивного тарифного ключа информера откройте «Источник погоды → Яндекс Погода — архивный тариф информера». Обычные REST-ключи используют `v2/forecast`.

Интеграция следует [документации REST API](https://yandex.ru/dev/weather/doc/ru/concepts/forecast-rest): фиксированный HTTPS-хост и заголовок `X-Yandex-Weather-Key`. В URL ключ не включается, перенаправления не выполняются. Ключ хранится в приватных данных приложения на ТВ, не вшит в APK и исключён из резервных копий и диагностики. Его можно удалить отдельной кнопкой.

Без подключения Яндекса используется Open-Meteo; это явно указано на экране и в виджете. При сбое подключённого Яндекса источник молча не подменяется. Ссылка «Открыть Яндекс Погоду» открывает страницу выбранных координат в установленном браузере без API-ключа.

## Обновление и сбои

Обновление выполняется каждые 30 минут, пока открыт главный экран или экран погоды. При переходе в другие приложения запрос отменяется; фонового сервиса нет. Вручную обновить можно кнопкой «Обновить сейчас».

Виджет показывает источник и время получения. После двух часов сводка отмечается как устаревшая. При ошибке последняя сводка и её время сохраняются; повтор — через 5 минут. На экране погоды отдельно объясняются отказ в доступе, лимит, DNS, TLS и тайм-аут. Неполные ответы не становятся нулевой температурой. Ответ для прежнего города после смены города игнорируется.

Для выбора города доступны 21 встроенный вариант, онлайн-поиск и ручные координаты. Список и координаты не зависят от доступности поиска; загрузка погоды требует интернет. Геолокация не запрашивается. Виджет можно скрыть и вернуть через инструменты.

## Проверка и установка

Версия 4.0.2, код 19, пакет `com.gathin.tvhome`. Устанавливается поверх предыдущей нашей сборки без удаления; подпись и настройки сохраняются.

392 JVM-теста и шесть сценариев на эмуляторе Android TV 9 прошли; Android Lint без ошибок. [Проверка эмулятора](https://github.com/aqaq136/TV/actions/runs/42128348915). Сценарии API используют детерминированные HTTPS-ответы, включая успешный ответ Яндекса и отказ 403. Рабочего личного ключа в окружении нет: живой запрос к Яндексу не подтверждён. На физическом Sber TV новая версия отдельно не проверена. Итоговые результаты эмулятора и подпись готового APK — в [VALIDATION.txt](../../downloads/VALIDATION.txt).
