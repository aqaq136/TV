# MetoxTV 3.5.0

Поиск и управление приложениями, резервные копии и настройка быстродействия для ежедневного использования пультом.

## Пользователю

Лупа в шапке открывает экран «Поиск и приложения». Поиск работает без интернета по названию и имени пакета, понимает регистр, диакритику и русский транслит: `kino` найдёт «Кинопоиск». Все слова запроса должны совпасть; точные названия идут первыми. Каталог и иконки загружаются в фоне, результаты выводятся переиспользуемыми строками.

Вкладки «Все», «Избранное» и «Недавние» позволяют быстро вернуться к нужному приложению. OK запускает приложение, удержание OK или Menu открывает действия. Избранное сохраняет свой порядок. Недавние учитывают успешные запросы запуска через MetoxTV: основные плитки, избранное, библиотеку и поиск. Это не история просмотра и не отслеживание активности других приложений. Запись можно остановить, сохранённые времена — очистить.

«Инструменты → Резервные копии и восстановление» сохраняет ZIP в выбранное системным окном место. Для импорта сначала проверяются структура, версия, размеры, типы и диапазоны настроек. Только после проверки появляется подтверждение замены. Перед записью сохраняется прежняя локальная копия; её можно вернуть кнопкой отмены последнего восстановления. При ошибке записи выполняется попытка возврата прежних данных. При отключении питания во время записи может потребоваться эта отмена вручную. Восстановление нескольких файлов и SharedPreferences не является одной транзакцией Android.

В копию входят:

- имя приветствия, тема, крупные подписи, отступы и форма плиток;
- избранные пакеты в их порядке, ярлыки главного экрана и порядок плиток;
- настройки анимаций, часов и звуков;
- выбранный город и координаты погоды, без устаревшей сводки;
- пользовательские обои `premium-wallpaper.jpg`, если они сохранены в приложении.

Приложения, история запусков, привязанные к прошивке темы `config.json`, внешние наборы обоев, разрешения и автозапуск не переносятся. Отсутствующие переносимые параметры возвращаются к значениям по умолчанию. Копия содержит персональное имя, город и пакеты избранных приложений: её следует хранить как личный файл. Облачной загрузки нет.

Предел импортируемого ZIP — 6 МиБ; распакованных данных — 6 МиБ, изображения — 4 МиБ, каждого текстового файла — 64 КиБ. Изображение ограничено 4096 пикселями по каждой стороне и 8 миллионами пикселей всего. Имена записей заданы в коде: произвольные пути и повторные записи отклоняются. Резервные копии другой программы не поддерживаются.

«Анимации и быстродействие» предлагает быстрый режим без анимаций, сбалансированный и все эффекты. Таймер часов при простое работает только на главном экране. Действия пульта описаны во встроенной справке. Новые строки интерфейса есть на русском и английском; другие языки используют английский текст.

## Обновление

`com.gathin.tvhome`, `versionCode 16`, `versionName 3.5.0`. Установка поверх прежнего нашего APK: `adb install -r MetoxTV.apk`. Подпись упакованного APK должна совпадать с опубликованной 3.4.1; проверка сертификата обязательна при подготовке файлов. Системный Home не изменяется установкой APK.

Файлы из GitHub Actions подписываются отдельным временным отладочным ключом CI и предназначены для проверки на чистой установке. Для обновления существующей установки используйте APK из `downloads/`, а не артефакт CI.

## Проверки

JVM-набор: 344 теста, включая 23 новых теста поиска и формата резервных копий. Сценарии охватывают транслит, порядок результатов, сохранение типов, пустое избранное, неверные версии, неподдерживаемые поля, обход путей, слишком большие распакованные записи и повреждённые данные. Android Lint выполнен без ошибок; предупреждения остаются.

GitHub Actions собирает вариант с оптимизацией кода, запускает JVM-тесты и Lint, сохраняет отчёты. Автоматической установки на телевизор или публикации очередного APK нет.

Физический Sber SDX-50U4010B и эмулятор для этой версии не использовались. Сообщение владельца о работе версии 3.4 не является проверкой версии 3.5.0.

## Проверка на телевизоре после установки

1. Открыть лупу стрелками. Найти приложение по части названия и транслитом. Проверить пустой результат и очистку запроса.
2. Открыть приложение из поиска и вернуться. Проверить «Недавние» и сохранение фокуса.
3. Добавить приложение в избранное, убрать ярлык с главного экрана, вернуть его из поиска. Проверить Menu и удержание OK.
4. Сохранить резервную копию на флешку. Изменить тему и избранное. Восстановить копию, вернуться на главный экран; проверить тему, порядок и обои. Отменить последнее восстановление.
5. Попробовать повреждённый ZIP: ошибка должна появиться до изменения настроек.
6. Переключить быстрый режим, проверить пульт и возврат фокуса. Включить часы на 2 минуты: приложение с видео не должно прерываться.
7. Остановить запись истории, открыть приложение, проверить отсутствие новой записи. Очистить прежнюю историю.
8. Проверить открытие системных настроек и возврат к штатному домашнему экрану доступным в прошивке способом.
